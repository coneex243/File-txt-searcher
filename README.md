# FileSearchApp (transferstil2.py)

Графическое приложение на Python (Tkinter) для пакетного поиска текстовой информации по регулярным выражениям (RegEx) в файлах различных форматов.

## 🚀 Основные возможности

- **Поддержка популярных форматов файлов:**
  - Текстовые файлы (`.txt`) — построчное чтение с кодировкой UTF-8.
  - Таблицы CSV (`.csv`) — чтение строк с разделением ячеек через ` | `.
  - Таблицы Excel (`.xls`, `.xlsx`) — обработка листов через `pandas`.
  - Базы данных SQLite (`.sqlite`, `.db`) — автоматический обход всех пользовательских таблиц и поиск по всем полям строк.
- **Гибкий поиск по регулярным выражениям:**
  - Поддержка синтаксиса Python `re`.
  - Валидация корректности регулярного выражения перед стартом.
- **Информативный интерфейс:**
  - Выбор входной папки и пути сохранения отчета через системные диалоговые окна.
  - Индикатор выполнения (Progress Bar).
  - Встроенное окно логов для отслеживания хода сканирования и ошибок чтения.
- **Экспорт результатов:**
  - Сохранение всех совпадений в текстовый `.txt` файл с указанием исходного файла (и имени таблицы для SQLite).

## 📋 Требования и установка

Для работы приложения необходим Python 3.8+ и следующие зависимости:

```bash
pip install -r requirements.txt
```

Содержимое `requirements.txt`:
- `pandas` — чтение таблиц Excel.
- `openpyxl` — движок для чтения файлов `.xlsx`.
- `xlrd` — движок для чтения файлов `.xls`.

*(Модули `tkinter`, `sqlite3`, `csv`, `re`, `os` входят в стандартную библиотеку Python).*

## 💻 Запуск приложения

```bash
python transferstil2.py
```

## 🛠 Порядок работы

1. В поле **Обзор** выберите папку, содержащую файлы для анализа.
2. В поле **Шаблон для поиска** введите регулярное выражение.
3. В поле **Путь для сохранения результатов** укажите имя и путь выходного текстового файла.
4. Нажмите кнопку **«Начать поиск»**.
5. По завершении поиска отобразится окно с количеством найденных совпадений, а результаты будут сохранены в указанный файл.
